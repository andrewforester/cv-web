# retro/layers/new

Why it exists: the 15 damage layers only `/new`'s show needs (`retro-new-1`), where `/`'s files
don't fit the profile's blocks: the impact figures as a 2 × 2 table of bevelled cells, the dark
"How I build with agents" panel as a black ridge box with a decimal list, `/new`'s section ids for
the frame, rules, padding and the "NEW!" bursts, the "Contact me:" line. The look and what each
file holds: `docs/design/retro/SPEC.md` → 2001 `/new` → Damage layers; the files are copies of
`docs/design/retro/new/layers/`, kept in step.

Registered in `../../scenarioNew.ts` next to the 17 shared files of `../`; removed by one chunk
each in `../../scenarioNewSteps.ts`. Some share an id with a `/` file (`heading-colors`,
`page-frame`, `bullets` …): ids are unique per scenario and only one show runs at a time. Every
rule of `../AGENTS.md` applies here.
