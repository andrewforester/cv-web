## 2. Experience: job block layout
Structure of each job, top to bottom:
1. **Header row:** logo 44×44 (radius 12, bg `#F7F4FB`), gap 12px. Right of the logo: company name (18px/600), with the period on the same line pushed right (JetBrains Mono 12.5px `#8C859A`, nowrap). Below that, role (15px `#5E5770`) and the optional stats line.
2. **Badge + description row:** left-aligned with the **logo's left edge** (no indent). `display:flex; align-items:center; gap:8px`, text 15px/1.5 `#5E5770`.
   - Badge: JetBrains Mono 11.5px, color `#8A3FE0`, bg `#F4EAFE`, radius 6px, padding 2px 7px.
3. **Bullets:** left-aligned with the logo's left edge (no indent). Gap between items 8px, text 16px/1.55 `#2A2433`.

Vertical gap between the three parts: 12px.

## 3. Transcenda project sub-blocks (SpotOn, Cync, August Home)
